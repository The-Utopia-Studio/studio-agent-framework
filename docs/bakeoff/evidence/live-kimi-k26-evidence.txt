--- WORKAROUND REQUIRED (D-39) ---
Moonshot's Anthropic-compatible endpoint returns a `thinking` content block with NO
`signature` field. @ai-sdk/anthropic's response schema requires content[].signature to be
a string, so EVERY Kimi call fails validation as "Invalid JSON response" -- while the HTTP
call itself returns 200 with a correct tool_use. Probed directly:

  kimi-k2.6 default             content types: ['thinking', 'tool_use']
                                thinking keys: ['thinking', 'type']   <-- no 'signature'
  kimi-k2.6 thinking=disabled   content types: ['tool_use']

Fix: providerOptions: { anthropic: { thinking: { type: 'disabled' } } } in the agent's
defaultOptions. Verified on the wire: '--> body.model: kimi-k2.6 | thinking: {"type":"disabled"}'
